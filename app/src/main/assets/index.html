Four Display Studio

First implementation — not hardware-tested. Replacing a slideshow erases images on all four displays and cannot be rolled back. Keep this app open during uploads.

Each display is 16 × 16 pixels. Slots run left-to-right, then top-to-bottom. Changing layout rearranges existing tiles; reimport a whole-wall image to split it differently.

Durations apply to the phone preview only. Stored hardware slideshows use the display's own playback timing; this controller does not set it.

Send to all four displays

Every step sends one image to each display, including black images for empty slots. Uploads are sequential; all four displays must be connected. Upload does not automatically start playback.

Saved sequences

Save explicitly before leaving a sequence. Images are copied into app-private storage. Uninstalling or clearing app data deletes the library. Export a backup first.

Display assignments

Assign only your own displays. Scan lists nearby BLE devices, not just compatible ones. Initial slot order is top-left, top-right, bottom-left, bottom-right for a 2 × 2 wall.

Diagnostic log

Logs may contain Bluetooth addresses. Redact them before sharing. Upload completion means commands were sent, not that device storage was read back.
