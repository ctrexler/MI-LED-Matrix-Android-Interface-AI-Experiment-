LED Matrix Controller

Version 0.5.0 · Selected displays and collections

About

An experimental Android controller for up to four Merkury Innovations multicolor matrix LED displays. Create image sequences, patterns and shapes; preview temporarily or upload stored slideshows.

Using the app

Assign displays in Displays and choose their physical arrangement. Slots run left to right, then top to bottom. Use Editor to compose, and Save to keep named sequences in Library. Live Preview sends temporary images; it does not add them to stored collections.

Send to displays lets you choose connected destinations. Replace erases only those destinations. Append uses the existing storage commands and timing. Start stored slideshow lets you choose destinations independently.

Stored Images

These are app-maintained records, not verified device read-back. Older contents and changes made elsewhere are unknown. Partial means prior images were not known. Uncertain means a transfer may have stopped partway. Editing creates a local draft; Apply clears and rewrites that display. No individual-device delete or reorder protocol is assumed.

Privacy and backups

Library and storage records are saved on your phone. Backups now include Bluetooth addresses used to associate stored-image records with physical displays. Keep backups private. Export before uninstalling; an APK signed with a different key cannot update an existing installation directly.

Limitations

Live Preview speed and cross-display synchronization depend on hardware and connection timing. Stored collections are not automatically readable from the devices. This update has not been hardware-tested by its author.
