# LED Matrix Controller

An Android application for controlling up to four Merkury Innovations multicolor matrix LED displays over Bluetooth LE.

## Features

- **Multi-display layouts**: 2×2, 4 across, or 4 stacked.
- **Composition tools**: Image import with scaling, multi-color patterns, gradients, and custom shapes (heart, star, circle, square, diamond, triangle, arrow, dots, zigzag, stripes, checkerboard).
- **Display modes**: Spanning across all displays, repeating per display, or targeting individual panels.
- **Live Preview & Stored Slideshows**: Live temporary frame preview or upload sequences directly to on-device memory.
- **Selective upload & playback**: Choose specific ready displays to replace or append without affecting other displays.
- **Per-display stored collection management**: Tracked images, draft editing, reordering, and display-to-display copying.
- **Library & Backups**: Save sequence projects locally, export/import library and display assignments.
