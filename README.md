# MI-LED-Matrix-Android-Interface-AI-Experiment-
Experimenting with AI coding through Perplexity. I purchased 4 Merkury Innovations Multicolor Matrix LED Displays and have been prompting the model to design a custom Bluetooth interface to drive them in various ways.
